# VISOMATIC — Visual Editing Studio

A high-end visual editing studio website built with React and Tailwind CSS.

## ✦ Sections


1. **Header**: Brand monogram, handwritten tags, and clean navigation.
2. **Hero**: *"High-End Editing for Visual Creators"* with studio timeline console.
3. **Services**: Video Editing, Motion Graphics, and Color Grading with checklists.
4. **Process**: 4-step workflow from footage ingest to final review and export.
5. **Portfolio**: Curation state with private sample request and modal viewer.
6. **About**: Real studio focus on crisp cuts, clean graphics, and proper color, plus turnaround specs.
7. **FAQ**: Direct answers on turnarounds, file sharing, and revisions.
8. **Contact**: Formspree-powered contact form with service selector.
9. **Footer**: Navigation links, brand mark, and back-to-top trigger.
